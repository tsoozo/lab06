## Хэсэг A: Category-Partition — POST /transfer

**Бие даан тестлэгдэх функц:** `POST /transfer {from, to, amount, currency}`. Код байхгүй, зөвхөн тодорхойлолт дээр тест дизайн хийсэн (shift-left).

### A1. Сонголт ба төлөөлөх утгууд (A2-ийн хязгаарлалтын хамт)

| # | Параметр | Сонголт | Төлөөлөх утгууд ба хязгаарлалт |
|---|---|---|---|
| 1 | from | from дансны төлөв | хүчинтэй · царцаагдсан **[ERROR]** · байхгүй **[ERROR]** |
| 2 | to | to дансны төлөв | хүчинтэй (from-оос өөр) · царцаагдсан **[SINGLE]** · байхгүй **[ERROR]** · from-тэй ижил **[ERROR]** |
| 3 | amount | Дүнгийн тэмдэг | эерэг · 0 **[ERROR]** · сөрөг **[ERROR]** |
| 4 | amount | Хөрвүүлсний дараах дүн ба from-ийн үлдэгдэл | үлдэгдлээс бага · яг тэнцүү **[SINGLE]** · үлдэгдлээс их **[ERROR]** |
| 5 | *(далд орчин)* | Өдрийн лимит өнөөдөр хэр ашиглагдсан | огт ашиглаагүй · хэсэгчлэн · бүрэн дүүрсэн **[property limitFull]** |
| 6 | amount | Хөрвүүлсний дараах дүн ба үлдсэн лимит | үлдсэн лимитээс бага **[if !limitFull]** · яг тэнцүү **[SINGLE] [if !limitFull]** · үлдсэн лимитээс их **[ERROR]** |
| 7 | currency | Валют ба from дансны валют | ижил · өөр (ханшаар хөрвүүлнэ) |

### A2. Хязгаарлалтын үндэслэл

- **[ERROR] (8 утга):** from царцаагдсан/байхгүй, to байхгүй/ижил, amount 0/сөрөг, үлдэгдэл хэтэрсэн, лимит хэтэрсэн. Эдгээр нь бусад сонголт ямар ч байсан шилжүүлгийг шууд зогсоож ERROR_* буцаадаг тул тус бүрд ганц тест хангалттай.
- **[SINGLE] (3 утга):** «яг тэнцүү» хоёр утга нь хязгаарын (boundary) тохиолдол бөгөөд амжилттай байх ёстой тул нэг удаа шалгахад хангалттай. «to царцаагдсан» нь тодорхойлолтод дурдагдаагүй (to-д зөвхөн байх, өөр байх шаардлага бий) тул тодорхойлолтын цоорхойг нэг тестээр шалгана.
- **[property limitFull] / [if !limitFull]:** өдрийн лимит бүрэн дүүрсэн бол үлдсэн лимит 0 тул ямар ч эерэг дүн лимитээс хэтэрнэ. Иймд «лимитээс бага/тэнцүү» утгууд зөвхөн лимит дүүрээгүй үед утгатай.

**Тооцоо:**

| Алхам | Тооцоо | Тоо |
|---|---|---|
| Бүрэн олонлог | 3 × 4 × 3 × 3 × 3 × 3 × 2 | **1944** |
| + ERROR, SINGLE | Энгийн утгууд: 1·1·1·1·3·1·2 = 6, + 8 ERROR + 3 SINGLE | **17** |
| + IF (limitFull) | «бүрэн дүүрсэн» нь «лимитээс бага»-тай хослох боломжгүй: 1·1·1·1·2·1·2 = 4, + 8 + 3 | **15** |

**1944 → 17 → 15**

### Олон алдааны давуу эрэмбэ

Нэг хүсэлтэд хэд хэдэн алдаа зэрэг байвал дараах эрэмбээр **эхний** алдаа буцна гэж тогтоосон:

`ERROR_NO_FROM → ERROR_FROZEN → ERROR_NO_TO → ERROR_SAME_ACCOUNT → ERROR_BAD_AMOUNT → ERROR_INSUFFICIENT → ERROR_LIMIT`

**Үндэслэл:** өгөгдөл хэрэгтэй болох дарааллаар шалгана: from данс байхгүй бол царцаасан эсэх, үлдэгдлийг нь мэдэх боломжгүй; дүнгийн формат (≤ 0) буруу бол хөрвүүлэлт, үлдэгдэл, лимитийн тооцоо утгагүй; үлдэгдэл бол дансны бодит хязгаар тул лимитээс өмнө шалгана.

- **16:** үлдэгдэл ч, лимит ч хэтэрсэн. Эрэмбээр ERROR_INSUFFICIENT.
